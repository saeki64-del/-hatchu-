# 発注書（外装部材の発注書づくり）Windows版

外壁・軒天の部材を、写真を見ながら選ぶだけで発注書が作れるソフトです。無料で使えます。

- 対応メーカー：城東テクノ・ニチハ・ケイミュー・神島化学
- 本体を選ぶと、合う役物（出隅・入隅・ジョイントなど）が順番に出ます
- 送信先・邸名を入れて、PDFで送る・印刷・Excel用にコピー・CSVで保存ができます

## ダウンロード

| 種類 | ファイル |
|---|---|
| インストール版（おすすめ。デスクトップにアイコンができます） | [hatchu-setup.exe](https://github.com/saeki64-del/-hatchu-/releases/latest/download/hatchu-setup.exe) |
| インストール不要版（USBメモリなどに入れて使えます） | [hatchu-portable.exe](https://github.com/saeki64-del/-hatchu-/releases/latest/download/hatchu-portable.exe) |

いつでも最新版がダウンロードできます。新しい版が出たら、同じリンクからダウンロードして上書きインストールしてください。

動作環境：Windows 10 / 11（64ビット）

## インストールのしかた

1. 上の「hatchu-setup.exe」をダウンロードして開きます。
2. 「WindowsによってPCが保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
   （個人で作ったソフトのため、この表示が出ます）
3. 画面にしたがって進めると、デスクトップに「発注書」のアイコンができます。

はじめて開いたときに、下の「ご利用にあたって（免責事項）」が出ます。内容をご確認のうえ「上記に同意して使う」を押してください。
